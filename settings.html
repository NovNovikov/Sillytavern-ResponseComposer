Multi-Stage Response Composer
Stages run strictly in order. MAIN uses normal SillyTavern generation and cannot be removed. Static Text blocks add text without an LLM request. Their conditions can test the previous additional block’s processed output with a JavaScript RegExp, or run a Quick Reply. A Quick Reply must return true, 1, yes, or on through its final pipe value. It receives {{arg::previousOutput}}, {{arg::blockId}}, {{arg::blockName}}, and {{arg::pipelineType}}. Output Extraction accepts a JavaScript RegExp; its first capture group is used when present.
